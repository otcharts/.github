## OTCharts

Charts and market data for the OTC books of **Pocket Option, Quotex, IQ Option and BinoDex**, and the real forex market: [otcharts.com](https://otcharts.com)

**A free API key, no SSID.** None of these brokers publishes an official API. OTCharts holds its own connection to each price feed and serves candles and live prices as JSON with a key of your own. Your broker login and session are never involved, and it is read-only: it cannot place trades.

| Repository | What it is |
|---|---|
| [pocket-option-api](https://github.com/otcharts/pocket-option-api) | Free Pocket Option API: runnable Python and curl examples |
| [quotex-api](https://github.com/otcharts/quotex-api) | Free Quotex API: runnable examples |
| [iq-option-api](https://github.com/otcharts/iq-option-api) | Free IQ Option API: runnable examples |
| [otcharts-python](https://github.com/otcharts/otcharts-python) | The Python client: `pip install otcharts` |
| [skills](https://github.com/otcharts/skills) | A skill for AI coding agents: `npx skills add otcharts/skills` |

**Start in a minute:** make a free account at [otcharts.com](https://otcharts.com), create a key on your account page, then `pip install otcharts`.
